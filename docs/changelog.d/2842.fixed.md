- `rh uninstall` removes the Global Working Rules block only when install proves it managed (equal to a released block or to the current render of its recorded language). An edited block leaves the file byte-identical and gives `[unresolved] <path>: managed rules block was edited; preserved`. Codex hook trust entries in `[hooks.state]` now give a `[note]` item, so a user who trusted the hooks reaches `[uninstall] complete` and the install state is retired. (#2842)
