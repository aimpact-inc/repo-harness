- `rh review publish` resolves the earlier-round review threads that the receipt names in its new `confirmed_fixed` field. It posts a `review reply` that cites the acceptance record on each thread, then resolves the thread. It refuses, with nothing posted, an id that is not an unresolved thread opened by an earlier `review publish` round of the same PR, by an account with write access. It stops at the first failed reply or resolve, and names the record URL and the resolved and unresolved thread ids. The publish receipt is now protocol 2; a protocol 1 receipt is refused (#2768).
