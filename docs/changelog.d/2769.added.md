- `rh seats argv <seat> --repository-id <id> --owner-exception <url>` lifts the Claude quota reservation refusal for one launch. The URL must name an issue or PR of the checkout's origin repository; the seat label `repo-harness.owner-exception` and the `--json` launch record keep it. A new `seats.routing.unavailable_pi_providers` list (default empty; `rh update` adds it) names Pi model prefixes such as `magpie/anthropic` that routing skips; `rh quota` route lines name the provider, and a direct launch refuses with `seat_provider_unavailable`.
