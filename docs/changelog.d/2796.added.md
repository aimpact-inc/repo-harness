- A new read-only review seat `gatekeeper-deep` (default Codex `gpt-6.1-sol`, high; tools `net`, `read`, `shell`; no `edit`, no `gh`, no fleet) gives a project a second Codex review row on a different model without a writer seat. `rh seats argv gatekeeper-deep --pr <n>` launches it, `rh quota` prints its own route line, and `rh update` adds the default to a stored seats section. A host that ran `rh update` and then downgrades must remove the `gatekeeper-deep` key first. (#2796)
